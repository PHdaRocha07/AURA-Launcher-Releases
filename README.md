# AURA Launcher — Releases oficiais

Este repositório publica os APKs assinados do AURA Launcher e o manifesto usado pelo atualizador interno.

- APKs: consulte a aba **Releases**.
- Manifesto de atualização: [latest.json](./latest.json).
- Código-fonte privado: https://github.com/PHdaRocha07/AURA-Launcher.

Instale apenas APKs publicados nas Releases deste repositório. O Android exibirá sua própria confirmação de instalação e verificará a compatibilidade da assinatura. Não desinstale uma versão existente sem antes fazer backup das preferências quando necessário.

Este repositório é somente o canal público de distribuição; não contém a chave privada de assinatura.
